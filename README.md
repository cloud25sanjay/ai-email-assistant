
# AI Email Assistant

An AI-powered Email Assistant built using Java and Spring Boot.

## Tech Stack

- Java 25
- Spring Boot 4.1.2
- Maven
- PostgreSQL
- LangChain4j (planned)
- Ollama with Qwen 2.5 7B (planned)
- Kafka (planned)

## Current Features

- Basic chat REST API
- Request validation
- Centralized project structure
- Unit testing

## Project Goal

Build an AI assistant that can understand user requests, retrieve relevant emails, summarize messages, and help create email drafts.

Email sending will require explicit user approval.

## Getting Started

Run the application using:

```bash
./mvnw spring-boot:run
```

On Windows:

```powershell
.\mvnw.cmd spring-boot:run
```
